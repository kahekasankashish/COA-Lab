# 8085 Assembly Programs

## Programs

| File | Practical |
|---|---|
| `01_Addition_of_Packed_BCD_Digits.asm` | Write an 8085 program to add the two decimal digits stored in the higher and lower nibbles of the byte at 2020H and store the result at 2050H.|
| `02_BCD_Addition_with_Decimal_Adjust.asm` | Write an 8085 program to add two packed BCD numbers using DAA and store the BCD result and carry separately at 2020H and 2021H.|
| `03_Subtraction_of_Two_8_Bit_Numbers.asm` | Write an 8085 program to subtract the contents of register B from register A and store the result at memory location 2020H.|
| `04_Multiplication_by_Repeated_Addition.asm` | Write an 8085 program to multiply two numbers using repeated addition and store the 8-bit product at 2020H.|
| `05_Square_of_a_Number.asm` | Write an 8085 program to calculate the square of the number stored at 2050H using repeated addition and store the result at 3050H.|
| `06_Fibonacci_Series_Three_Iterations.asm` | Write an 8085 program to generate and store a Fibonacci sequence beginning with 0 and 1, using three loop iterations.|
| `07_Fibonacci_Series_Sixteen_Iterations.asm` | Write an 8085 program to generate and store a Fibonacci sequence beginning with 0 and 1, using sixteen loop iterations.|
| `08_Largest_of_Two_Numbers.asm` | Write an 8085 program to find the larger of the two numbers stored at 2020H and 2021H and store the result at 2052H.|
| `09_Smallest_of_Two_Numbers.asm` | Write an 8085 program to find the smaller of the two numbers stored at 2050H and 2051H and store the result at 2052H.|
| `10_Largest_Among_N_Numbers.asm` | Write an 8085 program to find the largest among N numbers stored sequentially in memory, with N at 2100H, and store the largest value at 2106H.|
