# COA Lab

This repository contains lab assignments and practical programs for the **Computer Organization and Architecture (COA)** course. It includes 8085 Assembly Language programs and MATLAB programs covering various mathematical, matrix, logical, and computational operations.

## Repository Structure

```text
COA-Lab/
│
├── 01_8085_Assembly/
│
├── 02_MATLAB/
│   ├── 07_MATLAB_Commands_and_Functions/
│   ├── 08_MATLAB_Matrices_Vectors_and_Plotting/
│   ├── 09_MATLAB_Mathematical_and_Vector_Computations/
│   ├── 10_MATLAB_Strings_and_Matrix_Operations/
│   ├── 11_MATLAB_Scripts_and_Functions/
│   └── 12_MATLAB_Logic_Gates_Adders_and_Shift_Operations/
│
├── .gitignore
└── README.md
```

## Topics Covered

### 1. 8085 Assembly Language

- BCD addition and arithmetic operations
- Addition, subtraction and multiplication
- Square calculation
- Fibonacci series generation
- Finding the largest and smallest numbers
- Loop-based and data manipulation programs

### 2. MATLAB

- MATLAB commands and built-in functions
- Matrix and vector operations
- Matrix concatenation and plotting
- Mathematical and vector computations
- String and character operations
- MATLAB scripts and user-defined functions
- Conditional statements, loops and recursion
- Logic gates and adders
- Logical and arithmetic shift operations

## Software and Tools

- **8085 Assembly:** An 8085 assembler or simulator
- **MATLAB:** MATLAB environment

## Purpose

This repository serves as a collection of COA laboratory programs, maintained for academic reference, practice and revision.
