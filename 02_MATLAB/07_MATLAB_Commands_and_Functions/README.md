# COA Lab — MATLAB Assignment 07

## Assignment 07: MATLAB Command and Function Demonstrations

- **Section I:** Workspace, file/folder, and environment commands.
- **Section II:** Array tests, existence checks, and logical functions.
- **Section III:** Mathematical, rounding, and complex-number functions.

## Files

| File | Contents |
